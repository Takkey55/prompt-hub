### プロンプトの実行手順とカスタマイズのコツ

会議直後は誰しも次の仕事に追われ、議事録の整形は後回しになりがちです。このプロンプトを使えば、散らかった走り書きを貼るだけで即座にSlackやNotionに共有できる完成形が出力されます。

#### 1. Claude Codeでの実行方法
ローカルに保存したメモファイル（例: `meeting-raw.txt`）がある場合、Claude Codeに以下のように指示するだけで、ファイル出力まで一気通貫で完了します：

```bash
claude "meeting-raw.txt を読み込んで、議事録テンプレートに従って整形し docs/meeting-20260322.md として保存して"
```

#### 2. 出力精度を上げるコツ
- **担当者の曖昧さ排除**: メモの中で「誰がやるか」が明記されていないタスクがある場合、「※担当者未定のため要確認」とプロンプトに赤字注記させるルールを入れておくと、タスクのボールが宙に浮くトラブルを防げます。
- **Slack通知用ショートバージョン**: 議事録の全文だけでなく、冒頭の「エグゼクティブサマリー」と「アクションアイテム表」だけをSlackにそのまま貼ることで、多忙な経営陣やチームメンバーへの報告が完了します。
