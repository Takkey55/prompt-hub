### プロンプトの実行手順とカスタマイズのコツ

このプロンプトは、ターミナルで動作する **Claude Code** または Web UI 版の Claude 3.7 Sonnet でそのまま活用可能です。

#### 1. Claude Codeでの実行方法
Claude Code CLIが有効化されている環境では、プロジェクトルートで以下のコマンドを実行し、プロンプトをそのままパイプまたはプロンプト引数として渡すことができます。

```bash
claude "ターゲットキーワード: Astro Tailwind メディア構築 について、指定のSEOアウトラインを作成して"
```

#### 2. カスタマイズのコツ
- **ペルソナの詳細化**: BtoB向け、初心者向け、上級者向けなど、想定読者のITリテラシーや課題深度を書き換えることで、より刺さる見出し構成にシフトできます。
- **検索意図の深掘り**: 自社製品や有料コンテンツへの自然な導線（CTA設置場所）をあらかじめ「H2の最後に『次のステップ』として設定」と条件付けると効果的です。
- **Claude Codeとの連携**: 実際に競合上位のMarkdownファイルやスクレイピング結果テキストがある場合は、ディレクトリ内のファイルをClaude Codeに直接読ませて比較分析させることも可能です。
